**Grounding check on the advisory:**

The advisory allocates 80, 32, 8 across component sizes 1000, 400, 100, which samples each at rate 0.08 (8%). This is **pure proportional-to-size allocation**, ignoring within-component standard deviations entirely.

The advisory is dominated. It concentrates runs on component 1 (size 1000, low noise σ₁ = 1, gets 80 runs) while starving component 3 (size 100, high noise σ₃ = 6, gets only 8 runs). This is backwards: high-noise strata should receive *more* sampling effort per unit size, not less.
