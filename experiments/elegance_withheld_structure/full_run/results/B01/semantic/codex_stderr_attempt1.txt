# agent-review

Worker self-review against the diff you are about to ship. Auto-detects engine:

- **codex_cli** — when `codex` is on PATH and `CODEX_HOME` is set, delegate to native `codex review`
- **chat_complete:CLAUDE_SONNET_46** — fallback for Claude Code and other workers; uses `app.llm_gateway.chat_complete`

Both engines emit the same evidence JSON consumed by `AGENT_REVIEW_CLEAN` in `app/services/ralph_auto_verifier.py`.

## When to run

Run this **before** writing your completion packet, after the last fix-up commit. The Ralph dispatcher injects an instruction to run it for any code task (`contract_state.is_code_task == true`).

## Canonical invocation

From the repo where your work landed (typically `/Users/kevincthomas/src/talkingback-fastapi`):

```bash
# Review the uncommitted working tree against HEAD (default)
scripts/agent-review --task-id <ID>

# Review work between main and HEAD on the current branch
scripts/agent-review --task-id <ID> --base main

# Review a single commit
scripts/agent-review --task-id <ID> --commit <sha>

# Add a parallel test command — its non-zero exit is treated as an actionable finding
scripts/agent-review --task-id <ID> --base main --parallel-tests 'pytest -q tests/api/test_foo.py'
```

Flags you usually want:

| Flag | Purpose |
|---|---|
| `--task-id <ID>` | Persist evidence to `artifacts/task_<ID>/agent_review_evidence.json` AND `task.details.agent_review_evidence` |
| `--base main` | Review the full branch diff (preferred when the worker has already committed) |
| `--parallel-tests CMD` | Run tests alongside the review; failures count as actionable findings |
| `--engine codex_cli` / `--engine chat_complete` | Force a specific engine (otherwise auto-detect) |
| `--model CLAUDE_SONNET_46` | Override the model when using chat_complete (default is sonnet 4.6) |
| `--max-iterations N` | Cap review passes (default 3) |
| `--dry-run` | Print engine + diff summary without invoking the model |

## What "clean" means

Exit code 0 means: the engine emitted no **actionable** findings, OR every actionable finding from a prior iteration has been fixed (carries a `fixed_in_commit`). Advisory/speculative findings are recorded as `rejected_findings_history` and do not block.

`AGENT_REVIEW_CLEAN` predicate further requires:

- `final_clean_at` >= the worker's latest commit timestamp (review must run **after** the commit)
- `head_sha_at_clean` matches the current HEAD of the worktree (review is not stale)
- No unresolved entries in `accepted_findings_history`

If you commit again after running `agent-review`, you must re-run it before closing out — the predicate will FAIL on a stale sha.

## Handling findings

The script writes evidence with two arrays:

- `accepted_findings_history` — findings the worker accepted. Each must end up with `fixed_in_commit` set before the predicate passes.
- `rejected_findings_history` — findings the worker reviewed against the real code and rejected as speculative; include a short `reason`.

Re-runs auto-resolve accepted findings that no longer appear in the diff (they get `fixed_in_commit` set to the new HEAD).

## Worker workflow

1. Land your last code change and commit.
2. Run `scripts/agent-review --task-id <ID> --base <base-branch>`.
3. If exit 1: read the actionable findings, fix or reject them in code, commit, re-run.
4. When exit 0: include `agent_review_evidence` in your completion packet's `tests_checks_run` summary and reference the artifact path in `artifact_paths`.

## Troubleshooting

- **"agent_review_env_missing" / exit 2 on chat_complete**: required provider key absent after stash promotion. Claude Code launchers unset `ANTHROPIC_API_KEY` (subscription auth) but must stash it as `TB_AGENT_REVIEW_ANTHROPIC_API_KEY` so agent-review can promote it. Do **not** silently fall back to a weaker model and claim `AGENT_REVIEW_CLEAN` — record the env-missing reason and stop.
- **"engine error" on chat_complete**: missing `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `DEEPSEEK_API_KEY` for the selected model, or the local FastAPI app environment is not on `PYTHONPATH`. Run from the repo root.
- **codex_cli engine errors**: `codex` not on PATH, or `CODEX_HOME` unset. Force `--engine chat_complete` when running outside a Codex CLI container.
- **Evidence not picked up by the predicate**: the predicate reads `task.details.agent_review_evidence`. The script writes there automatically when `--task-id` is set and `SQLALCHEMY_DATABASE_URI` is exported. Otherwise, paste the JSON into `task.details` via a separate update.
