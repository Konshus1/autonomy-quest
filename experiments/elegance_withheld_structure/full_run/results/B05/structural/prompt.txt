Public API and data-format contract (the implementation's internal organization is unrestricted):
Expose the string constant `DELETE = "__DELETE__"` and `load(defaults, project, user, environ, explicit, schema, secrets=())`. The first three and `explicit` are nested dictionaries (`user` may be `None`); `environ` is a dictionary whose dotted keys identify settings; source precedence, low to high, is defaults, project, user, environ, explicit. Nested mappings merge, lists replace, and a value equal to `DELETE` removes that key and its descendants. `schema` maps dotted keys to one of `"bool"`, `"int"`, `"path"`, `"csv"`, `"str"`, `"list"`, or `"mapping"`. Environment values and other scalar candidates for declared fields are converted: bool accepts case-insensitive `true/yes/on/1` and `false/no/off/0`; int uses base-10; path produces `pathlib.Path`; csv splits on commas and strips each part; str requires a string. `list` and `mapping` require those types. Keys absent from `schema` (except prefixes of declared dotted keys) are unknown. All unknown-key and conversion errors are accumulated, sorted, and do not raise.
`load` returns an object with attributes `data` (the successfully resolved nested dictionary) and `errors` (list of strings), and methods `get(dotted_key, default=None)` and `explain(dotted_key)`. Errors are exactly `unknown key <dotted>` or `invalid <dotted> from <source>: expected <type>`, where source is `defaults`, `project`, `user`, `environ`, or `explicit`. An invalid candidate does not replace the last valid value. `explain` returns candidates in source precedence order as a list of dictionaries with `source`, `status` (`selected`, `overridden`, `removed`, or `invalid`), and `value`. Only candidates actually supplied for that key are listed. For keys in `secrets`, every explanation value other than `None` is the literal `"***"`, including invalid and removed candidates. An absent key explains as `[]`. Neither arguments nor nested contents may be mutated.
