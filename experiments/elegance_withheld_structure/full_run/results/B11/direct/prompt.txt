Implement `labels.py`. An exhibit label contains a title, creator names, date ranges, dimensions, narrative paragraphs, quoted text, and credit lines. Generate labels for locales `en`, `fr`, and `ja`, for wall, mobile, and accessible-audio uses. Locale changes punctuation, name order, number/date presentation, and available translations; use the supplied translation dictionary only. Missing translations fall back to source text but must be reported. Mobile has a length budget and may omit optional paragraphs; credit lines may never be omitted. Accessible audio must verbalize symbols and image descriptions. Return output plus omissions/fallbacks.

Executable acceptance contract: Fixed fixture asserts exact name/date/dimension presentation per locale, quote punctuation, mobile optional omission but retained credit, audio symbol expansion, fallback diagnostics, deterministic output, and no calls to locale/global environment (tests can patch `locale.setlocale` to fail). Use only the Python standard library.

Public API/data-format contract: `generate_label(exhibit, locale, use, mobile_budget=None) -> dict`. Inputs and outputs are JSON-shaped values. `exhibit` has `title`, `creators` (each `{given,family}`), `date` (`{start,end}` ISO dates, with equal dates allowed), `dimensions_cm` (`[height,width]` numbers), `paragraphs` (each `{id,text,optional}`), `quotes` (strings), `credits` (strings), `image_descriptions` (strings), and `translations`, a mapping from locale to a mapping from source string to translated string. `locale` is `en`, `fr`, or `ja`; `use` is `wall`, `mobile`, or `audio`. The result is `{text, omissions, fallbacks}`, where the latter two are sorted lists of source paragraph IDs and untranslated source strings. Translation is looked up independently for every title, paragraph, quote, credit, and image description; `en` source strings need no dictionary entry. Names render “given family” in en/fr and “family given” in ja. Dates render `YYYY-MM-DD` in en, `DD/MM/YYYY` in fr, and `YYYY年M月D日` in ja; a range joins with `–`, while equal endpoints render once. Dimensions render `H × W cm` in en/fr and `H × W cm` in ja, using ordinary decimal text without trailing `.0`. Quotes use “…” in en, « … » in fr, and 「…」 in ja. A non-audio label consists, in order, of title, creators joined by `, `, date, dimensions, included paragraphs, quotes, and credits, joined by newline. For mobile, repeatedly omit optional paragraphs from the end until UTF-8-decoded character length is at most `mobile_budget`; if mandatory content alone exceeds the budget, return it unchanged. Credits are mandatory. Audio has no budget or omissions and joins the same fields plus image descriptions by newline, but replaces `&`, `×`, and `%` in all rendered text with locale words (`and/times/percent`, `et/fois/pour cent`, `と/かける/パーセント`). Invalid locale/use raises `ValueError`. The function must not mutate its input.
