Observations include observer, local time with explicit UTC offset, location, species label, count, optional photo hash, and notes. Produce a canonical export, daily/site/species summaries, possible-duplicate groups, and a reconciliation report. Exact photo matches are duplicates; otherwise records are only “possible” duplicates when supplied tolerances for time and coordinates and compatible species aliases hold. Staff may decide that a group is same or distinct, and future imports must honor that decision. Preserve original spellings and rows for audit.

Executable acceptance contract: Use `csv`, `json`, and `datetime`; cover offsets crossing UTC date, aliases, exact hash duplicate, near-but-not-certain pair, persisted same/distinct decisions, summaries before/after reconciliation, stable canonical export under import order reversal, and original-row recovery. Public API/data-format contract: Provide class `Survey(time_tolerance_seconds, coordinate_tolerance)`. `import_csv(text)` accepts columns `id,observer,local_time,latitude,longitude,species,count,photo_hash,notes`; `import_json(rows)` accepts equivalent dicts. IDs are nonempty and unique. Local times are ISO-8601 strings with explicit offsets. The object exposes `possible_duplicates() -> list[dict]`, `decide(member_ids, decision)`, `summaries() -> dict`, `canonical_export() -> str`, `reconciliation_report() -> dict`, and `original_row(id) -> dict`. A duplicate group dict is `{group_id,members,reason}` with sorted member IDs; `reason` is `photo` for equal nonempty hashes and otherwise `possible`. Its `group_id` is the first 16 lowercase hex characters of SHA-256 over comma-joined sorted member IDs. Non-photo pairs qualify only if absolute UTC-time difference is within the supplied inclusive tolerance, Euclidean latitude/longitude distance is within the supplied inclusive tolerance, and their species labels are compatible. Species aliases are supplied by `set_aliases(mapping)`, where each key maps to a list including all compatible spellings; matching is case-insensitive, but original spelling is retained. `decide` accepts exactly a currently reported member list and `same` or `distinct`; decisions survive later imports. `same` collapses those observations to one resolved observation for summaries, using the lexicographically smallest ID as representative; `distinct` prevents that exact group from being reported or collapsed. Exact equal hashes collapse unless explicitly decided distinct. Summaries returns `{daily,site,species}` maps of summed counts keyed respectively by UTC date, `"latitude,longitude"` using input decimal text, and representative original species spelling. Each collapsed group contributes the maximum member count. Canonical export is compact JSON (`sort_keys=True`, separators `(',',':')`) containing observations sorted by ID and decisions sorted by member list, and is independent of import order. The report is `{groups,decisions}` in deterministic group/member order. `original_row` returns all originally supplied field strings (JSON numeric values converted to their input `str` form) and a `source` key (`csv` or `json`). No method mutates returned values.
