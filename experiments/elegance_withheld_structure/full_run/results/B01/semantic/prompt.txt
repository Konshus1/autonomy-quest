HTML is one `<section><h2>...</h2>...</section>` per included section; item elements are respectively `<p>`, `<p class="measurement" data-unit="..."><strong>label:</strong> value unit</p>`, `<p class="warning">`, `<p class="reference">text <a href="url">[n]</a></p>`, and `<img src="path" alt="alt">`. If used, references are an `<ol class="references">` whose `<li>` elements contain linked titles. All user-provided strings, including attributes, are escaped with `html.escape(..., quote=True)`.
