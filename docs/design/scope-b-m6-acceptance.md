# Scope B M6 exact composed acceptance

M6 adds no new authority. It is the final exact, fresh, opt-in acceptance proof over M0-M5.

The non-skipping proof must use fresh Compose state and freshly built images; assert exact runtime
principals and trusted owners/ACLs; use an independently grounded promotion in the real Loop
pre-ACT route; prove its contradiction creates no run and no ACT; prove its matching plan creates
one receipt-bound run and one ACT; let the independent evaluator recover the mandatory outcome
from durable backlog on service startup and repeat restart without duplication; independently
refute that same used promotion and prove it disappears from the next authority assessment.

The proof must also inspect the built ACT child environment allowlist and show it contains none of
the loop, governance, evaluator, decision, or trigger credentials. It must prove
`AQ_GOVERNED_FEEDBACK` remains `0` when not explicitly enabled. Missing services/DSNs, skips,
xfails, xpasses, deselection, count shrinkage, unexpected exits, reused state, or a weaker substitute
are rig failures. M6 does not merge or push.
