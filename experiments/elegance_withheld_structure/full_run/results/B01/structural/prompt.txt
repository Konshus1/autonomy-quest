It must render deterministic plain text, HTML, and JSON. Each render selects an audience clearance; material above it is omitted, but a section whose body disappears must not leave an empty heading. References are numbered in first-use order in the rendered result, repeated references reuse a number, and broken references are reported before rendering. Public API and data-format contract (the implementation's internal organization is unrestricted):
`Report(sections, sources)` accepts `sections` as a list of dictionaries and `sources` as a mapping from source ID to `{"title": str, "url": str}`. Each section is `{"title": str, "items": list}`. Each item has `kind` (`paragraph`, `measurement`, `warning`, `reference`, or `image`), optional `clearance` (`public` by default or `admin`), and these fields: paragraph/warning: `text`; measurement: `label`, `value`, `unit`; reference: `source`, `text`; image: `path`, `alt`. Inputs must not be mutated. `validate(report)` returns a sorted list of strings, with a missing source reported exactly as `missing source: <id>`.
`render(report, format, clearance)` accepts format `text`, `html`, or `json`, and clearance `public` or `admin`; unknown values raise `ValueError`. A section is omitted when none of its items are visible. In text, sections use `## <title>`, paragraph text is literal, measurements use `<label>: <value> <unit>`, warnings use `WARNING: <text>`, references use `<text> [n]`, and images use `[Image: <alt>] (<path>)`; nonempty sections and the final reference list are separated by one blank line. The reference list is headed `References:` and entries are `[n] <title> — <url>`. There is no reference-list block if none are used, and the result has no trailing newline. HTML is one `<section><h2>...</h2>...</section>` per included section; item elements are respectively `<p>`, `<p class="measurement" data-unit="..."><strong>label:</strong> value unit</p>`, `<p class="warning">`, `<p class="reference">text <a href="url">[n]</a></p>`, and `<img src="path" alt="alt">`. If used, references are an `<ol class="references">` whose `<li>` elements contain linked titles. All user-provided strings, including attributes, are escaped with `html.escape(..., quote=True)`. JSON is a deterministic JSON object with keys `sections` and `references`; each included section has `title` and `items`, and each item retains its kind-specific fields (a measurement retains separate `value` and `unit`); reference items additionally contain integer `number`. `references` is a first-use-ordered list of objects with `number`, `id`, `title`, and `url`. JSON must parse with `json.loads` and deterministic rendering uses stable key ordering.
